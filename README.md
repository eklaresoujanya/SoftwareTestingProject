# 🧪 Software Testing Project

This repository showcases a structured approach to manual software testing, including a detailed **Test Plan** and comprehensive **Test Cases**.

## 📋 What's Included

- **Test Plan** – Defines testing scope, objectives, environment, and strategy  
- **Test Cases** – Step-by-step cases with inputs, expected results, and status tracking  
- **Reports** – Space for execution logs and outcome summaries  
- **Clean folder structure** – Easy to navigate and understand

## ✅ Key Skills Demonstrated

- Manual testing & documentation  
- Writing effective test cases  
- Understanding of QA processes  
- Organized and professional project structure
